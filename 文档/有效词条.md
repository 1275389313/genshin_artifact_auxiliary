# 有效词条（角色装配页）

贴图主数字改为社区口径的「有效词条」，不再用刻晴办公桌旧版 30/40/50 加权分作为主显示。截图、OCR、格子坐标与右键识别链路未改。

## 怎么用

1. 游戏设为窗口或无边框，**16:9 / 16:10**（优先 1080p、1440p）。启动后不要移动游戏窗口。
2. **管理员**运行 `keqing.exe`，或管理员命令行 `python app.py`（上游鼠标钩子需要）。
3. 工具里选角色。不选则按「常规主C-攻暴」（双暴+攻击）。`character.json` 里没有的角色同样回退，并在工具窗口提示。
4. 勾选 **角色**，游戏内打开 **角色 → 圣遗物装配**。
5. 按 **F8**（可在设置里改）或点「扫描五件」：自动依次左键花 → 羽 → 沙 → 杯 → 冠，OCR 右侧详情，把有效词条贴在该部位右下角，然后停止。不会点其它 UI。再扫一次会覆盖。
6. 背包或角色格子：**右键**仍识别单件，贴图主数字同样是有效词条。背包不做整页扫描。
7. 清除贴图：全局 **Ctrl+Shift+Z**（与上游相同）；焦点在贴图上时 **Ctrl+Z** 去掉当前这块。

扫描中途工具窗口会先藏一下，避免挡在左侧页签上。合计在工具窗口和角色页页签下方：`有效词条 28.4`，未扫完为 `有效词条 12.3（3/5）`。

## 公式（一句话）

副词条数值 ÷ 五星单词条最大值，保留一位小数；`文档/keqing/character.json` 里系数 **> 0** 才计入，系数只做过滤，不乘 `coefficient.json` 的 2.0 / 1.33。`攻击力` / `生命值` / `防御力` 只放行对应 **百分比**；小攻击/小生命/小防御默认不计。

分母：暴击率 3.89，暴击伤害 7.77，攻击%/生命% 5.83，防御% 7.29，充能 6.48，精通 23.31。

## 旧评分

设置里「显示旧版加权评分」默认关闭。打开后工具窗口会显示原来的 30/40/50 分，不抢贴图主数字。

角色配置仍在 `文档/keqing/character.json`，系数在 `coefficient.json`。本功能另写 `settings.json`（快捷键等），不会清空你已有的 json。
