# 有效词条（角色装配页）

贴图主数字改为社区口径的「有效词条」，不再用刻晴办公桌旧版 30/40/50 加权分作为主显示。截图、OCR 与角色装配页五件扫描链路未改。

## 怎么用

1. 游戏设为窗口或无边框，**16:9 / 16:10**（1080p、1440p、**4K 3840×2160** 均可；不必再强制 1920×1080）。**原神不能最小化**（任务栏图标即可，不要点最小化）；`GetWindowRect` 出现 **-32000** 就是 Windows 最小化窗口的哨兵坐标，不是 4K/DPI 算错。启动时若窗口最小化或还没开，工具会提示并继续进入界面，**不会一直卡住**；F8 前会先尝试还原窗口并重算坐标。**改分辨率后无需死磕重启——扫描前会重算；但原神不能最小化。** 建议无边框；150%/200% 系统缩放由程序按 DPI 处理。
2. **管理员**运行 `keqing.exe`，或管理员命令行 `python app.py`（上游鼠标钩子需要）。
3. 工具里选角色。不选则按「常规主C-攻暴」（双暴+攻击）。`character.json` 里没有的角色同样回退，并在工具窗口提示。
4. 游戏内打开 **角色 → 圣遗物装配**（工具只有这一模式，已无背包页）。
5. 按 **F8**（可在设置里改）或点「扫描五件」：自动依次左键花 → 羽 → 沙 → 杯 → 冠，OCR 右侧详情，把有效词条贴在该部位右下角，然后停止。不会点其它 UI。再扫一次会覆盖。扫描结果会出现在工具窗口下方（只读，五件摘要），并按当前角色自动写入 `文档/keqing/equipped.json`。下次选中同一角色会立刻显示上次扫描。
6. 清除游戏内贴图：主窗口 **「清除贴图」**，或全局 **Ctrl+Shift+Z**（同一套逻辑）；焦点在贴图上时 **Ctrl+Z** 去掉当前这块。不删除已保存的角色扫描。

扫描中途工具窗口会先藏一下，避免挡在左侧页签上。**F8 时原神需在最前**；工具会尝试自动置顶。合计在工具窗口显示，游戏内合计贴图放在五部位数字**下方**（避免挡住单件词条）：`有效词条 28.4`，未扫完为 `有效词条 12.3（3/5）`。

## 公式（一句话）

副词条数值 ÷ 五星单词条最大值，保留一位小数；`文档/keqing/character.json` 里系数 **> 0** 才计入，系数只做过滤，不乘 `coefficient.json` 的 2.0 / 1.33。`攻击力` / `生命值` / `防御力` 只放行对应 **百分比**；小攻击/小生命/小防御默认不计。

分母：暴击率 3.89，暴击伤害 7.77，攻击%/生命% 5.83，防御% 7.29，充能 6.48，精通 23.31。

## 旧评分

设置里「显示旧版加权评分」默认关闭。打开后工具窗口会显示原来的 30/40/50 分，不抢贴图主数字。

角色配置仍在 `文档/keqing/character.json`，系数在 `coefficient.json`。五件扫描按角色存在 `equipped.json`。本功能另写 `settings.json`（快捷键等），不会清空你已有的 json。

5.8～7.0 新角色参考配置已补进 `src/character.json`；启动时只会合并缺失角色到 `Documents/keqing/character.json`，个人改过的不会被盖掉。系数仅作有效词条开关。

## 4K / DPI

4K 16:9（及 16:10）按游戏窗口比例缩放坐标，不另做一套 4K 表。启动后看控制台：`物理桌面`、`SCALE`、原始 `GetWindowRect`、修正后 `x,y,w,h`、`ratio`。无边框 4K 应进 16:9/16:10，而不是「请改 1080p」。

Windows 冒烟：4K 无边框 16:9 → F8 贴图落在花/羽/沙/杯/冠，合计贴图在部位数字下方互不遮挡；「清除贴图」应立刻去掉游戏内贴图。有 200% 缩放时再试一次。还原窗口后扫描应看到 `ratio≈1.78`；若最小化再启动，界面应能出来（提示还原「原神」），不要空转卡住，也不要出现 PIL `Coordinate 'lower' is less than 'upper'`。1440p 用过后再切 4K，直接 F8 即可，不必重启工具。

## OCR 依赖

识别解析逻辑未改。`ocr.py` 跟随当前 `rapidocr` 默认模型（PP-OCRv6），不再强制 PP-OCRv5 small；启动时尽量开 DirectML，失败则回退 `RapidOCR()`。
